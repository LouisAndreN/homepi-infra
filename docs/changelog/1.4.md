Daily NILM energy archived (2026-11-27): the hourly downsample task also writes, per local day
(Asia/Tokyo) and per leg, the energy (`wh`) and the number of 5 min windows with data (`n5`) to
`iot-archives` (measurement `nilm_daily`), so the dashboard calendar keeps a year instead of the 30
days of `iot-hot`. The dashboard token is rotated to read `iot-archives` as well. Operator steps:
docs/runbooks/influxdb-nilm-daily.md.
