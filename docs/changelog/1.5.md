Remote update and restart of the NILM Teensy (2026-11-28): the Teensy 4.0 behind the NILM bridge is
a catalog project of its own (`homepi_nilm_teensy`, chip `teensy40`), signed with the OTA key by
`tools/teensy-sign.sh` (homepi-firmware) and rolled out by the same state machine as the ESP32 images,
through the bridge (firmware v2.6.0+, command `teensy_ota`). The registry keeps the Teensy version
(`devices.teensy_fw`, from `fw_teensy`); `POST /api/admin/devices/<id>/teensy-reboot` restarts it;
`/metrics/homepi` exposes its CT1 fault flag and self-restarts. Operator steps:
docs/runbooks/ota-teensy.md.
