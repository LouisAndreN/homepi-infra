NILM calibration on the Pi (2026-11-27): firmware v3 publishes raw normalised V, I, P and Q, and
`homepi-nilm-calibrate` (a Telegraf execd processor) applies `/var/lib/homepi/nilm/calibration.json`
(V and I scale, phase per CT; the phase also absorbs the CT orientation), reloaded without a restart,
raw fields kept. The admin API stores and versions the file; the dashboard wizard calibrates
differentially with a kettle and checks the result end to end.
