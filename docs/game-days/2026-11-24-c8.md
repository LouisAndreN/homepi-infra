# Game day C8, 2026-11-24: the first restore without any error, R7 to R8 included

## Context

C7 (same evening) ran every restore phase at its first attempt in 49 min 26 s, but the return of
production (R8) had to be run twice: the DNSSEC probe of R6 ran three minutes after the boot, on an
empty Unbound cache. v0.4.3 fixed it (the probe retries for up to 90 s; `homepi-r8-return` waits
until Unbound validates before the apply). C8 runs the same scenario on v0.4.3: the production NVMe
(Micron 2200) is removed, the platform is rebuilt on the spare (Samsung 990 PRO) from the signed
GitHub repository and the age-encrypted archives in S3 only, then production comes back and the
drill key leaves SOPS. Drill directory on the laptop: `~/homepi-restore/drill-20261124-2327`.

Rule, written before C7 and not changed since (docs/versioning.md): the drill is clean only if no
code changes during it, no phase runs twice and no step is redone, from R0 to the SOPS step of R8.

## Defects

None. The C7 defect did not come back: `homepi-r8-return` waited for Unbound to validate before the
apply, and R6 on production passed at its first run.

## What the numbers do not say

- The native time series archive is daily (03:50): its RPO of 19 h 38 min is inside the 24-hour
  target only because C8 started late in the evening. The hourly sensor deltas cover that gap
  (21 min 45 s); everything else in the native archive is lower-value history.
- R4SITE took 11 min 54 s (11 min 45 s in C7): the full `site.yml` on a cold Pi is
  now the longest phase. It is not a target, and no work is planned on it before a need appears.
- One clean drill is one measurement, not a guarantee. The next drills run on every minor that
  changes the restore procedure (docs/versioning.md).

## What went well

- Nothing was typed between T0 and R6 except the three physical steps (T0, SD, BOOT).
- The microSD system was found without an address twice (SDCHECK and R9).
- The signature of v0.4.4 and v0.4.5 went through the drill agent, which was stopped at the end.
- The spare left the drill erased (R9, fifth run on the hardware).
