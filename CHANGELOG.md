# Changelog

Releases are signed tags applied by the GitOps agent (docs/versioning.md). Generated by
`scripts/changelog` from the tag annotations; the summaries are in `docs/changelog/`.

## 1.1

Service level objectives (2026-11-25): ingestion 99.5% and device API 99% over 28 days, time-based
SLIs where a minute without a sample counts as bad, multiwindow burn-rate alerts, and a release
policy when a budget is spent (docs/slo.md). The 2026-11-22 incident, replayed in the tests, would
have spent the device API budget by a third more.

- `v1.1.4` 2026-11-25: Restore drill tags listed in CHANGELOG.md; C9 plan and verdict rules
- `v1.1.3` 2026-11-25: ship: release a reviewed branch, main back in place when the release fails
- `v1.1.2` 2026-11-25: CI: checkout v6 (Node 24); the changelog job reads the annotated tags
- `v1.1.1` 2026-11-25: SLO rules in one group, so their tests give one result; CI can run by hand
- `v1.1.0` 2026-11-25: SLOs and error budgets, CI on every push (minor: a release policy, R6 does not count SLO alerts)

## 1.0

The platform is proven, not only built (2026-11-25). C8 rebuilt it on a blank disk from the signed
repository and the S3 archives in 48 min 08 s, then returned production and rotated the drill key
out of SOPS, without a code change, a phase run twice or a step redone
(docs/game-days/2026-11-24-c8.md). Sensor data lost: 21 min 45 s. No device re-enrolled. Five full
rebuilds came before it: C3 5 h 18 min with 44 defects, C4 4 h 24 min, C5 1 h 03 min, then C6 and
C7, both under 1 h 30 min but not clean.

- `v1.0.1` 2026-11-25: Alerts inhibited by real dependency only; alert tests run in every release precheck
- `v1.0.0` 2026-11-25: C8: first restore drill without any error, RTO 48 min 08 s (major)

## 0.1

From the first reproducible baseline to the first measured rebuilds (2026-10-27 to 2026-11-23).
GitOps from signed tags, pulled from GitHub (v0.1.32), checked on the Pi before signing (v0.1.47),
one Ansible runtime on the laptop and the Pi (B11). AWS through Terraform and IAM Roles Anywhere:
off-site backups every hour, a dead man's switch. Every running service adopted into Ansible, either
managed or verify-only: network, PKI, nginx, the provisioning API, Authelia, InfluxDB, Telegraf,
Grafana, Unbound, CrowdSec, step-ca. Device identity and revocation enforced at the broker, signed
OTA images with a staged rollout, the restore scripts, and two full rebuild drills: C3 (5 h 18 min,
44 defects) and C4 (4 h 24 min, 17 defects). It ends with the 2026-11-22 API outage and its fixes.
Every release raised the patch, including procedure changes: the patch was a deployment counter
(docs/versioning.md).
